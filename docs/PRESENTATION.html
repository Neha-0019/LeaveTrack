Problem & Architecture

The Business Problem & Technology Stack

Corporate leave tracking often suffers from manual overlap errors, unverified balance calculations, and complex approval bottlenecks.

  • Backend API: Python 3.11 & Flask 3.0 REST API.
  • Database: SQLite 3 with persistent disk support (`DATABASE_PATH`).
  • Frontend: Modern Vanilla HTML5/CSS/JS Single-Page Application.
  • Security: 16-byte token authorization, RBAC, and password complexity regex.
Core Innovations

Key Business Logic & Features

Weekend Holiday Exclusions

Saturdays and Sundays are automatically excluded from leave duration calculations (e.g. Fri-Mon = 2 days).

Half-Day Leave Math

Supports 0.5-unit leaves on start and end dates with exact balance deduction.

Role-Adaptive Dashboard

Employees see Available Balance; Managers see Total Team Requests.

Printable HR Slips

One-click PDF/Printer slip generation with reference codes & manager approval stamps.

AI Change Loop

Automated Engineering & Test Orchestration

Demonstrating closed AI change loop with automated test validations.

  • Pytest Test Suite: 20/20 passing integration tests covering business rules & security.
  • Deliberate Red Run: Captured run output (`evidence/red_run.txt`) proving failure detection.
  • Evidence Log: Detailed record in `evidence/CHANGE_LOOP_LOG.md`.
