Create Your Accounts & Password Rules
• First Manager Created: Auto-assigned ID MG001
• First Employee Created: Auto-assigned ID EMP002
• Password Requirement: Minimum 6 characters including a letter, number, and special character (e.g. Admin@123).
1

Sign In & Role Mismatch Protection

  1. Select your role: Employee or Manager.
  2. Enter your ID code: Employee IDs start with EMP, Manager IDs start with MG.
  3. Enter your password (click the eye icon to toggle visibility).
  4. If you try to log in with an Employee ID on the Manager tab, LeaveTrack will automatically alert you to switch tabs!
2

Submitting a Leave Request

  1. Click the Overview tab in the navigation header.
  2. Choose your Leave Category: Casual (CL), Sick (SL), Earned (EL), or Parental.
  3. Select Start Date and End Date.
  4. Toggle Half Day switches if taking partial morning/afternoon leave.
  5. Type a clear reason for your absence and click Submit Request.
3

Tracking Application Audit Timeline

  1. Click the Tracker tab in the navigation header.
  2. Inspect your active requests with color-coded side borders:
    • Green Border = Approved
    • Red Border = Rejected
    • Gold Border = Pending Manager Review
  3. Follow the connected line between 1. Applied Time, 2. Manager Review, and 3. Final Decision.
4

Manager Approvals (For Managers)

  1. Sign in as Manager (`MG001`).
  2. Click the Approvals tab in the navigation header.
  3. Review the pending queue: inspect applicant's department, current remaining balance, and stated absence reason.
  4. Click Approve (triggers a festive confetti burst!) or Reject.
5

Printable HR Approval Slips

  1. Open the Tracker tab (or main Requests table).
  2. Find any approved leave application and click Print Slip.
  3. An official document pops up with reference code TAC-LV-2026-00X, manager sign-off stamp, and a Print / Save PDF button.
6

Team Absence Calendar & Filters

  1. Click the Calendar tab in the navigation header.
  2. Use the < Previous and > Next buttons to browse months.
  3. View scheduled team absence bars (Green = Approved, Gold = Pending).
  4. Use the Department Filter toolbar to filter by Engineering, Product, HR, Marketing, or Sales.
